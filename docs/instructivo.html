Instructivo de operación

Ruleta Exeltis es una aplicación portable y offline. Abre index.html para operar la dinámica.

Preparación

  1. Entra a Panel.
  2. Selecciona el módulo que se usará en el evento.
  3. Edita el nombre del módulo.
  4. Agrega participantes por nombre o pega una lista completa.
  5. Agrega PPIs, temas y una imagen relacionada cuando aplique.
  6. Usa Exportar JSON para respaldar la configuración.

Operación del evento

  1. Entra a Evento.
  2. Presiona Sortear participante.
  3. Cuando se revele el participante, presiona Girar ruleta.
  4. El resultado se registra automáticamente en el historial.
  5. Presiona Nueva ronda para continuar.
  6. Presiona Finalizar evento cuando el operador decida terminar.

Datos

Los cambios se guardan en el navegador con LocalStorage. Para mover la configuración a otra computadora, exporta el JSON y luego impórtalo en la otra máquina.

Imágenes

Las imágenes seleccionadas desde el panel quedan guardadas en la configuración local como datos embebidos. También puedes preparar un JSON con imagePath apuntando a archivos dentro de assets/images/.
